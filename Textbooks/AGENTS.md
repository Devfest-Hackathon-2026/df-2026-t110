# 教材

このディレクトリには、小学生向けのプログラミング教材のテキストが YAML 形式で記述されています。
YAML は [../Schema](../Schema) で定義されている形式に沿う必要があります。
また、小学生向けの日本語を使い、小学校で習わない漢字を使うことはできません。

求められた要件を満たす YAML を書けているかは、`pnpm lint` コマンドで確かめることができます。

```sh
pnpm lint # pages ディレクトリにある YAML ファイルすべてについて検査する
# or
pnpm lint pages/01.yaml # 特定のファイルだけを検査する
```

また、YAML は prettier でフォーマットを行います。

```sh
pnpm format
```
