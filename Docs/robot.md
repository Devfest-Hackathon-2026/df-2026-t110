# ロボット (robot)

ロボットの座標 (position) `r` $\in \{(x,y) \vert 0 \le x \lt W, \ 0 \le y \lt H, \ x,y \in \mathbf{N} \}$
ロボットの向き (direction) `d` $\in \{(0,1), (0,-1),(1,0),(-1,0) \}$

特に記述がない行動は、成否にかかわらず1ターンかかる。

- 前進 (forward)
  - 1ターンで `r = r+d` にする
  - `r+d` が岩や海の場合は進めない（その場にとどまる）
- 後退 (back)
  - 1ターンで `r = r-d` にする
  - `r-d` が岩や海の場合は進めない（その場にとどまる）
- 回転 (rotate)
  - 右か左に1ターンで90度回転する
  - 座標は変わらない
- 待機 (wait)
  - nターン何もしない。nが0以下なら即座に戻る
- 拾う (pick up)
  - `r+d` にある荷物を拾う。持てる荷物は1個まで
- 捨てる (release)
  - 持っている荷物を `r+d` の陸に置く。すでに荷物があるマスや岩には置けない
  - `r+d` が海なら荷物を落とす
- 岩を壊す (drill)
  - `r+d` の岩を壊す。残り回数はロボットごとに管理し、成功時に1回消費する
- 距離を調べる (distance)
  - `d` 方向にある指定した種類の最寄りの対象までのマス数を返す。対象がなければ `-1`
  - 自分自身と運搬中の荷物は対象外
- 前方・現在地を調べる (search_front, search_now)
  - それぞれ `r+d` と `r` の `terrain` を返す
- 残り掘削回数を調べる (drill_durability)
  - 自機の残り掘削回数を返す
- しゃべる
  - bool、integer、unit、terrain、rotation、distance_target の値を吹き出しで表示する

距離、地形、残り掘削回数の観測はターンを消費しない。
