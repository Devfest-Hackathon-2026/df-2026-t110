# ロボット (robot)

ロボットの座標 (position) `r` $\in \{(x,y) \vert 0 \le x \lt W, \ 0 \lt y \lt H, \ x,y \in \mathbf{N} \}$
ロボットの向き (direction) `d` $\in \{(0,1), (0,-1),(1,0),(-1,0) \}$
盤面上の向きは `north` = (0,-1)、`south` = (0,1)、`west` = (-1,0)、`east` = (1,0) とする。

特に記述が無い行動は、1単位時間かかる。

- 前進 (forward)
  - 1単位時間後に `r = r+d` にする
  - `r+d` が岩や海の場合は進めない（その場にとどまる）
- 後退 (back)
  - 1単位時間後に `r = r-d` にする
  - `r-d` が岩や海の場合は進めない（その場にとどまる）
- 回転 (rotate)
  - 右か左に1単位時間で90度回転する
  - 座標は変わらない
- 待機 (wait)
  - n単位時間何もしない
- 拾う (pick up)
  - `r+d`にある荷物を拾う
  - 荷物が無い場合は何もしない
- 捨てる (release)
  - `r+d`に持っている荷物を置く
  - 荷物を持っている場合は何もしない
  - `r+d`が海の場合は荷物を落とす
  - `r+d`が岩の場合は置けない
- 岩を壊す (drill)
  - `r+d`にある岩を壊す
  - 岩が無い場合は何もしない
  - フィールドごとに回数制限がある
- 距離を調べる
  - `d` 方向にある指定した種類のオブジェクトの距離を取得する
  - intを返す
  - 無い場合は -1 を返す
  - 時間0
- 1個前を調べる
  - `r+d`が指定した種類のオブジェクトかどうかを調べる
  - boolを返す
  - 時間0
- 現在地を調べる
  - `r`が指定した種類の特殊な陸かどうかを調べる
  - boolを返す
  - 時間0
- 残り岩を壊す回数を取得
  - 岩を壊す回数の制限の残りを取得する
- しゃべる
  - int や bool の値を吹き出しで表示する
