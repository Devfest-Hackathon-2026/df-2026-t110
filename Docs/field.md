# フィールド (field)

$F \in \{(x,y) \vert 0 \le x \lt W, \ 0 \lt y \lt H \}$

$(x,y) \in F$ の座標は以下のいずれか

- 陸 (land)
  - ゴール (goal)
    - 特殊な陸
    - チュートリアルなどで、最終的にロボットがいた場合にクリアとなる
  - チェックポイント (check point)
    - 特殊な陸
    - 番号を持つ
    - チュートリアルなどで、順番に回ることでクリアになる
  - 荷物 (luggage)
    - 特殊な陸
    - 荷物があってもロボットは通ることができる
- 岩 (rock)
  - ロボットはそこを通れない
  - 壊せる
  - 壊すと陸になる
- 海 (sea)
  - ロボットはそこを通れない
  - どうにもならない

$(x,y) \notin F$ の座標は海

通常の陸以外のものをオブジェクトと呼ぶ。
