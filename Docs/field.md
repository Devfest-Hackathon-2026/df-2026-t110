# フィールド (field)

$F \in \{(x,y) \vert 0 \le x \lt W, \ 0 \le y \lt H \}$

$(x,y) \in F$ の基本地形は以下のいずれか。

- 陸 (land)
  - ゴール (goal)
    - 特殊な陸
    - チュートリアルなどで、最終的にロボットがいた場合にクリアとなる
  - チェックポイント (check point)
    - 特殊な陸
    - 番号を持つ
    - チュートリアルなどで、順番に回ることでクリアになる
- 岩 (rock)
  - ロボットはそこを通れない
  - 壊せる
  - 壊すと陸になる
- 海 (sea)
  - ロボットはそこを通れない
  - どうにもならない

$(x,y) \notin F$ の座標は海

陸には荷物を1個まで置ける。荷物とロボットは同じマスに存在できる。

対戦の納品エリアは、チームが所有する通常の陸の集合。両チームのエリアは重ならず、どちらのチームも通行できる。荷物の有無はエリアの所属に影響しない。
